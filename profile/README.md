# Lumox Technologies

**Enterprise software, mobile applications, cloud platforms and private AI for complex Australian work.**

Lumox Technologies Pty Ltd is a Canberra software engineering company ([ABN 80 691 619 020](https://abr.business.gov.au/ABN/View?id=80691619020)) building enterprise software, native and cross-platform mobile applications, cloud platforms, private AI, integrations and ongoing support for Australian organisations.

Lumox takes on work that does not fit an off-the-shelf product or needs clear technical and operational ownership. That can include new operational platforms, complex integrations, customer and staff portals, application modernisation, workflow automation and websites that function as dependable business systems. Architecture, assurance, information handling, handover and support are defined for the actual operating context rather than assumed from a generic label.

Public product evidence: [Yaana](https://yaana.com.au/) is allied-health practice-management software developed and provided by Lumox; [Lumox Secure](https://secure.lumoxtech.com.au/) is a Lumox product for public website trust-verification records. These links provide inspectable product context, not claims about client outcomes or certifications.

Current guide: [Enterprise software readiness](https://lumoxtech.com.au/resources/enterprise-software-readiness-checklist/) sets out the ownership, information-boundary, assurance, recovery and handover decisions a consequential system should make explicit.

## How we work

Clear ownership, architecture, assurance, information handling, maintainable delivery and practical handover. We design around the real operating context: how information moves, who owns each decision, what happens when the normal path breaks and how the system is supported after launch.
